# BotDesk Mobility: Master M2M ENS Domain Registry
### The Definitive On-Chain Routing Directory for Autonomous Passenger Fleet Infrastructure

This registry catalogs the complete network of validated Ethereum Name Service (ENS) endpoints architecture owned and deployed by BotDesk Mobility. These endpoints route algorithmic interactions across 7 deployment steps, dividing the network into **128 custom domains for Robotaxi** and **124 custom domains for Rental** ecosystems.
